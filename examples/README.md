## 中文说明

这四张图用于验证 Skill 的默认合同：3:5 竖版、纸面占主导、单一视觉事件、一个明确强调色、没有可读文字。它们是专为本仓库生成的原创图像，并非对任何参考海报的重绘。

| 文件 | 输入的关系 | 载体与强调色 | 验收点 |
| --- | --- | --- | --- |
| `thread-through-paper.png` | 穿过与阻力 | 蓝色纸片、朱红定位点、黑线 | 信号集中在左下，纸面仍然开放 |
| `almost-touching.png` | 接近但未相触 | 炭灰与褪橙半圆 | 用微小缝隙表达关系，不增加叙事元素 |
| `torn-sky.png` | 被遮住的远方 | 撕纸、靛蓝、柠檬黄图钉 | 夜色只作为窄窗口，不成为全景 |
| `receipt-index.png` | 被分类的痕迹 | 票据轮廓、锈红胶带、薄荷绿点 | 像归档物，而不是商业海报 |

每个案例都通过了 `quiet-signal-press/references/quality-checklist.md` 的人工检查。后续新增案例应同时提供“输入关系、使用的配方、验收点”，而不只给一张图。

## English notes

These original repository examples test the default contract: 3:5 portrait, an open paper field, one visual event, one decisive accent, and no readable type. They are not redraws of a reference poster.

| File | Input relation | Carrier and accent | Check |
| --- | --- | --- | --- |
| `thread-through-paper.png` | passing through / resistance | blue paper, vermilion dot, black thread | compact lower-left signal |
| `almost-touching.png` | a near contact | charcoal and faded-orange semicircles | the gap does the work |
| `torn-sky.png` | a hidden distance | torn paper, indigo, lemon pin | sky stays a narrow reveal |
| `receipt-index.png` | an indexed trace | receipt contour, rust tape, mint dot | archive fragment, not an ad |
