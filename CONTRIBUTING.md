# Contributing

Thank you for helping make the visual system clearer without making it louder.

## What to submit

- A reproducible prompt or a small Skill/documentation improvement.
- An original, redistributable example with a one-line input relation, its chosen recipe, and the checks it passes.
- A reference-analysis test that separates transferable rules from source-specific residue.

## What not to submit

- Material containing third-party logos, readable text, watermarks, faces without permission, or unlicensed photographs.
- A near-copy of an existing poster, including its composition, wording, or signature marks.
- A dense ad, UI card, photo collage, or full-bleed campaign image presented as a default example.

## Pull requests

Keep changes focused. Add a concise explanation of the visual outcome you checked. If you alter a prompt recipe or quality rule, explain which default contract it protects: format, open field, single signal, material surface, or non-derivative handling.
